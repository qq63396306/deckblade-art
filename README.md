# 牌刃疾行 · 主角精致像素图提示词

给 GPT 生成主角和 13 个形象用的提示词，目标是 DNF 那种精致的横版格斗角色，但仍然是严格的像素画，放进游戏里不突兀。

## 用法

1. 把 `PROMPTS.md` 里的 **STYLE** 整段粘给 GPT（每次都要带上）。
2. 再粘一段 **CHARACTER**（先做 `hero · 晨霜`），最后粘一段 **OUTPUT**。
3. 如果能上传图片，把 `ref/hero-combo-1.png` 和 `ref/looks-lineup.png` 一起传上去当风格参考。
4. 顺序建议：先出晨霜的 A（站姿），满意后出 B（三视图），再拿定稿的站姿当参考出 C（动作条）。其他 12 个形象先只出 A。

## 第二轮返工（2026-11-10）

第一批图在 fork `0xuezhang985/deckblade-art` 的 `assets/standing/` 里。9 张保留，4 张重画：铜炮、虚空、余烬、夜鸦。另外晨霜三视图要改成每格 96×80，和动作条一致。

- 每张返工图的提示词：`PROMPTS.md` 的 **STYLE** 加上该角色的 **CHARACTER**，再加上 **REWORK** 里它的那段修改说明，按 OUTPUT A 出图。
- STYLE 新加了三条规则，以后所有图都适用：
  - 色块至少 2×2，不要孤立像素和杂点；64 像素高时每种材质最多 3 档色。
  - 原尺寸下也要认得出武器、帽子、护目镜这些关键道具。
  - 外轮廓一圈连续近黑描边，亮面要明显比深色背景亮。
- 上传 `ref/rework.png`（保留和返工的对照）和一张保留图（比如 `hero.png`），给 GPT 当色块大小和描边的样板。

## 第三轮：四张补细节（2026-11-10）

第二轮（fork 的 e6a6536）把铜炮、虚空、余烬、夜鸦的杂点清掉了，但它们比另外九张平很多：只有 8 到 11 色，内部几乎没有明暗，13 张放在一起像两种画风。这一轮保持第二轮的剪影、姿势和干净的边缘，只把内部细节补到和另外九张一样。

- 提示词：**STYLE** 加上该角色的 **CHARACTER**，再加 **THIRD PASS** 里的通用段落和它自己那段，按 OUTPUT A 出图。
- STYLE 的「干净色块」规则放宽了：每种材质 3 档明暗加 1 档高光；眼睛、铆钉、扣子、反光这种有意义的单像素可以有，只是不要随机杂点。
- 上传给 GPT：`ref/pass3.png`（上排是要达到的细节密度，下排是太平的第二轮）、该角色第二轮的 PNG 当底稿，再加 `hero.png` 和 `ironblood.png` 当细节密度的样板。
- 目标：12 到 14 色，每个部位都有明暗，脸、眼睛、手炮、子弹带这些要画清楚。

## 为什么这样写

- **尺寸**：游戏现在的主角只有 38 像素高，舞台 400×180。要做到 DNF 的精细程度，提示词把角色定在 64 像素高，让 GPT 按 8 倍放大画（512 像素高），拿回来再缩到 1/8。
- **跟现有画面统一的几条硬规则**：
  - 光从左上方偏前打来，和游戏里骨架渲染的光一致。
  - 每种材质 4 到 6 档平涂色阶，阴影偏冷。
  - 外轮廓是游戏同款的近黑色 `#0e0c14` 一像素描边。
  - 全角色最多 32 色。
  - 不要光晕、不要特效、不要地面阴影，这些由游戏里的 pixelfx 自己画。
- **配色**：每个形象的颜色直接取自游戏数据（`src/data/looks.js`），换了画法角色也认得出来。

## 拿回来之后

GPT 出的图通常不会严格对齐像素格。收到后先按 `PROMPTS.md` 末尾的清单检查，再缩放、对齐网格、压色板后才能进游戏。这一步由 Claude 处理。
