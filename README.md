# 牌刃疾行 · 主角精致像素图提示词

给 GPT 生成主角和 13 个形象用的提示词，目标是 DNF 那种精致的横版格斗角色，但仍然是严格的像素画，放进游戏里不突兀。

## 用法

1. 把 `PROMPTS.md` 里的 **STYLE** 整段粘给 GPT（每次都要带上）。
2. 再粘一段 **CHARACTER**（先做 `hero · 晨霜`），最后粘一段 **OUTPUT**。
3. 如果能上传图片，把 `ref/hero-combo-1.png` 和 `ref/looks-lineup.png` 一起传上去当风格参考。
4. 顺序建议：先出晨霜的 A（站姿），满意后出 B（三视图），再拿定稿的站姿当参考出 C（动作条）。其他 12 个形象先只出 A。

## 交付位置（固定，每一轮都一样）

GPT 每次做完都推到同一个地方，Claude 只在这里取图：

- 仓库 `0xuezhang985/deckblade-art`，分支 `art/dawnfrost-sprites`。不开新分支，不换仓库。
- 每轮在分支最上面加一个新提交再推送，不强推，不改旧提交。
- 返工直接覆盖原来的文件，路径和文件名不变：
  - 女角色部件：`assets/heroines/parts/<id>.png`、`x8/<id>.png`、`manifest.json`
  - 站姿：`assets/heroines/standing/<id>.png`
  - 晨霜：`assets/parts/`
- 提交说明第一行写明第几轮、改了什么。
- GitHub 上看得到这次推送，才算交付；交付时报一下提交号。

`PROMPTS.md` 开头的 **DELIVERY** 段就是这几条，每次随提示词一起粘给 GPT。女角色部件的第一轮返工要求在 **HEROINE PARTS rework 1**。

  - 原尺寸下也要认得出武器、帽子、护目镜这些关键道具。
  - 外轮廓一圈连续近黑描边，亮面要明显比深色背景亮。

## 第三轮：四张补细节（2026-11-10）

## 骨架部件：战斗里的主角（2026-11-10）

战斗里的主角由游戏自己的骨架驱动，所有技能都是骨架上的姿势。所以不再画动作条，而是把角色拆成部件画一次，游戏把每块转到对应的骨头上。先只做晨霜。

- 在 `parts/parts-template-8x.png` 上画（832×992，每格一个部件）。`parts-template-labelled.png` 是标了名字的同一张图。
- `parts/parts.json` 写着每个格子、红点（部件挂的关节）和蓝点（下一个关节）的位置。
- `parts/assembly-preview.png` 是灰色模板装到真实招式上的样子，让 GPT 明白部件是怎么用的。
- 提示词：**STYLE** 加晨霜的 **CHARACTER**，再加 **PARTS** 那段。上传模板、标注版、组装预览和 `assets/standing/hero.png`。
- 要点：
  - 纯侧面朝右，不要四分之三侧身。
  - 每个部件画完整，不要因为站姿里被手臂挡住就缺一块。
  - 四肢两端各多画 2 到 3 像素圆头，转动时关节不露缝。
  - 至少和灰色模板一样粗。
  - 每块单独描边。
  - 剑平放朝右，刃宽至少 5 像素。
- 画完可以用 `tools/assemble.py` 把部件装到同样的招式上检查。

## 为什么这样写

- **尺寸**：游戏现在的主角只有 38 像素高，舞台 400×180。要做到 DNF 的精细程度，提示词把角色定在 64 像素高，让 GPT 按 8 倍放大画（512 像素高），拿回来再缩到 1/8。
- **跟现有画面统一的几条硬规则**：
  - 光从左上方偏前打来，和游戏里骨架渲染的光一致。
  - 每种材质 4 到 6 档平涂色阶，阴影偏冷。
  - 外轮廓是游戏同款的近黑色 `#0e0c14` 一像素描边。
  - 全角色最多 32 色。
  - 不要光晕、不要特效、不要地面阴影，这些由游戏里的 pixelfx 自己画。
- **配色**：每个形象的颜色直接取自游戏数据（`src/data/looks.js`），换了画法角色也认得出来。
